# 运费审查

1. 确认目标是课程练习仓库，读取 `src/shipping.ts` 和调用方明确提供的 diff。
2. 使用以下业务契约：国内订单满 5000 分免基础运费，否则 500；国际基础费 2000；加急始终额外加 800。
3. 核对 4999、5000、5001 三个国内边界，并检查国际与加急组合。
4. 为每项发现提供文件、行号和影响；没有发现时说明检查范围，不能推断整个项目无缺陷。
5. 不修改代码，不运行 commit/push。测试只在实际获准并具有执行工具时运行。
6. 输出“发现”“证据”“已运行的验证”“未验证项”。不能把工具提示或模型结论代替真实验证。
